# Vapt Sofá Clean

Site institucional responsivo desenvolvido para a **Vapt Sofá Clean**, empresa familiar de higienização de estofados em Ribeirão Pires e região do ABC Paulista.

## Objetivo

Apresentar os serviços da empresa e facilitar pedidos de orçamento pelo WhatsApp.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Design responsivo
- GitHub Pages

## Funcionalidades

- Apresentação dos serviços
- Área de atendimento
- Processo de orçamento
- Integração direta com WhatsApp
- Link para o Instagram
- Layout adaptado para celular e computador
